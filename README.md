#### How I work
- **Research first:** interviews, competitive analysis, personas, journey maps, usability testing (Maze).
- **Design systems:** Figma variables exported as design tokens and used directly in code.
- **Build with the design in mind:** Next.js, TypeScript, Supabase (auth, RLS, realtime) and Vercel, with Claude Code as my pair programmer.
- **Arabic and English:** bilingual, RTL-ready interfaces.
